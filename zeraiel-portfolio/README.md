# Zeraiel — сайт-портфолио

Одностраничный сайт: HTML, CSS и немного JavaScript без сборки и зависимостей. Форма заявок
работает через небольшую функцию Cloudflare Pages (`functions/api/contact.js`), которая пересылает
сообщение в Telegram.

## Возможности

- Тёмная и светлая темы: берётся из системы, выбор запоминается, без мигания при загрузке
- Русский и английский: язык определяется по браузеру, выбор запоминается
- Адаптивная вёрстка, управление с клавиатуры, видимый фокус, ссылка «перейти к содержимому»
- Форма заявок с доставкой в Telegram
- Шрифты лежат в `assets/fonts` (Manrope и IBM Plex Mono, лицензия SIL OFL), запросов к чужим серверам нет

## Структура

```
index.html                 страница (разделы подписаны комментариями)
style.css                  все стили
js/config.js               ВАШИ НАСТРОЙКИ: ссылки, контакты, пути к картинкам
js/translations.js         все тексты, русский и английский
js/main.js                 поведение: язык, тема, меню, ссылки, форма
functions/api/contact.js   приём формы и отправка в Telegram (Cloudflare Pages Function, адрес /api/contact)
_headers                   заголовки безопасности и кеш шрифтов (Cloudflare Pages)
.dev.vars.example          образец секретов для локального запуска
assets/fonts/              шрифты и их лицензии
assets/projects/           сюда класть скриншоты проектов
```

## 1. Создать Telegram-бота (один раз, около 5 минут)

1. В Telegram откройте **@BotFather**, отправьте `/newbot` и ответьте на вопросы (имя бота и его адрес на `bot`).
2. BotFather пришлёт **токен** вида `123456789:AA…`. Это пароль: не публикуйте его, не кладите в репозиторий и не присылайте на скриншотах.
3. Откройте своего нового бота и нажмите **Start**. Бот может писать только тем, кто его запустил.
4. Узнайте свой **chat id**: напишите в Telegram боту **@userinfobot** (он ответит числом `Id`), либо откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` подставьте свой), отправив до этого боту любое сообщение.
   В ответе найдите `"chat":{"id":123456789`. Это число и есть chat id.

Если токен где-то засветился (скриншот, публичный репозиторий), отправьте `/revoke` в @BotFather и используйте новый.

## 2. Опубликовать на Cloudflare Pages

1. Создайте на GitHub репозиторий и загрузите в него содержимое этой папки (корень репозитория — там, где лежит `index.html`).
   `.dev.vars` в репозиторий попадать не должен, он уже в `.gitignore`.
2. На dash.cloudflare.com откройте **Workers & Pages → Create → Pages → Connect to Git** и выберите репозиторий.
3. Параметры сборки: **Framework preset — None**, **Build command — пусто**, **Build output directory — `/`** (или `.`).
4. После первого деплоя откройте проект → **Settings → Variables and Secrets** и добавьте для Production (кнопка **Encrypt/Secret**):
   - `TELEGRAM_BOT_TOKEN` — токен бота,
   - `TELEGRAM_CHAT_ID` — ваш chat id.
5. Нажмите **Deployments → … → Retry deployment** (или сделайте любой коммит): переменные применяются при следующем деплое.
6. Откройте `https://<имя-проекта>.pages.dev`, отправьте тестовую заявку. Сообщение должно прийти в Telegram.

### Необязательно: лимит «5 заявок в час»

Скрытое поле и таймер заполнения отсекают большинство ботов. Если нужен ещё и лимит по посетителю:

1. **Storage & Databases → KV → Create** — создайте хранилище, например `contact-rate`.
2. В проекте **Settings → Bindings → Add → KV namespace**: имя переменной **`RATE_LIMIT`**, выберите созданное хранилище.
3. Передеплойте. Теперь с одного IP принимается не больше 5 заявок в час и не чаще раза в 20 секунд.

## 3. Проверить локально

Нужен Node.js. Скопируйте `.dev.vars.example` в `.dev.vars`, впишите токен и chat id, затем:

```bash
npx wrangler pages dev .
```

Откройте адрес из консоли (обычно http://localhost:8788). Простое открытие `index.html` с диска форму не проверит:
функция работает только под сервером.

## Что делает функция

- Принимает только `POST` с JSON с этого же сайта
- Проверяет каждое поле (длина, допустимые типы проекта) и отвечает названием неверного поля
- Игнорирует ботов: скрытое поле, которое люди не заполняют, и минимальное время заполнения
- Необязательный лимит по посетителю (см. выше)
- Экранирует текст посетителя перед отправкой в Telegram и укорачивает слишком длинные сообщения
- Не пишет токен в логи

## Ссылки на странице

В `js/config.js` блок `site`: Telegram, почта, GitHub, демо проектов. Ссылка с пустым значением скрывается,
так что мёртвых ссылок на странице нет.

## Картинки

Портрет и три превью проектов нарисованы средствами CSS, поэтому сайт работает и без файлов. Чтобы использовать реальные:

- `assets/photo.jpg` — ваше фото
- `assets/projects/coffee.jpg`, `landing.jpg`, `app.jpg` — скриншоты проектов (удобнее всего широкие, превью высотой 270 px, обрезается сверху)

Если файла нет, остаётся рисунок. Другие имена и форматы можно указать в `js/config.js`.

## Превью при отправке ссылки (по желанию)

Когда будет известен адрес сайта, добавьте в `<head>` файла `index.html` (подставьте свой адрес и положите картинку 1200×630 в `assets/og.png`):

```html
<meta property="og:url" content="https://ВАШ-САЙТ.pages.dev/" />
<meta property="og:image" content="https://ВАШ-САЙТ.pages.dev/assets/og.png" />
<meta name="twitter:card" content="summary_large_image" />
```

## Тексты

Все видимые тексты в `js/translations.js`. Элемент в `index.html` с `data-i18n="ключ"` берёт текст из записи `ключ` (русский и английский рядом).
